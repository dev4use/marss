# A propos du site

Ce site a vocation pédagagique,  
- pour l'auteur afin de maintenir un peu ses compétences,
- pour tout lecteur qui souhaite examiner de près la démarche.

C'est un prétexte à utiliser d'autres outils :

- outil de tests,
- outil de couverture de test,
- outil de qualité de code,
- outil de mesure du code,
- outil de documentation.
