# Documentation de l'application Marss

Vous pouvez trouver ici plusieurs éléments :

## Documentation du code source

Les fonctions sont exposées dans l'ordre de la cinématique produit.  
Chaque fonction est commentée, et son code source est visible au besoin.  

- marss.html
- marss.md

## Analyse quantitative du code source

Des indicateurs intéressant sont disponibles en brut et en relatif.  
Exemple : connaître la taille du code source, le pourcentage des commentaires...  
Le datage des rapports permet de visualiser la progression.  

- code-marss-AAAAMMJJ.json

## Analyse qualitative du du code source

Le rapport consigne "les violations de la norme".  
Même si la norme n'est pas à respecter strictement,  
cela donne un indicateur du niveau d'écart avec des conventions de codage python.  
Le datage des rapports permet de visualiser la progression.  

- qualite-marss-AAAAMMJJ.json

## Documentation exécutable du système

Pour remplacer une documentation utilisateur jugée inutile, 
la documentation du système est disponible sous forme de [Feature en BDD](../Tests/Features/).

Cette documentation est exécutable en test et le rapport de test peut être visible en Tests/Report/
